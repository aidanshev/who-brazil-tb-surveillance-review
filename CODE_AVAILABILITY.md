# Code Availability

Suggested manuscript statement:

> A publication-focused source and decision-analysis repository is publicly available at https://github.com/aidanshev/who-brazil-tb-surveillance-review. It contains the materialized core surveillance-review modules, aggregate decision-analysis summary, upstream platform documentation, and provenance/safety records. The public tree is a source-rich extraction rather than a byte-for-byte mirror of the complete upstream working platform. Primary predictive evidence should be cross-cited to the corresponding WHO-global and Brazil forecasting repositories. Raw surveillance records and third-party image binaries are not redistributed.

After final reconciliation against the authoritative upstream platform, create an immutable archived release and add its DOI to this statement and the repository citation metadata.
